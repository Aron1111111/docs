## 恢复真正的分支与历史 / Восстановить ветки и историю

Скачайте git-case-history.bundle в отдельную рабочую папку и выполните в Git Bash:

```sh
git clone --branch main git-case-history.bundle git-case-restored
cd git-case-restored
git log --oneline --graph --all
git branch -a
git show v1.0.0:price.txt
git show origin/docs/readme-usage:readme.txt
```
