# 文档检查 / Проверка документации

从仓库根目录运行以下命令，需要 Python 3。
Запустите команду из корня репозитория; требуется Python 3.

```sh
python -B -X utf8 tools/check_docs.py
```

`-B` 禁止写入 Python 字节码缓存，`-X utf8` 启用 UTF-8 模式。两个选项可同时使用，保留 A、B 分支的意图。
`-B` запрещает запись кеша байт-кода Python, а `-X utf8` включает режим UTF-8. Параметры совместимы и сохраняют намерения веток A и B.

脚本检查必需文件、Markdown 相对文件链接和 PNG 文件头。完成后，终端会显示检查结果。
Скрипт проверяет обязательные файлы, относительные файловые ссылки Markdown и заголовки PNG. После завершения результат отображается в терминале.
