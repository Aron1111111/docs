# 测试设计 / План тестирования

以下业务用例根据已有 OpenAPI 规范设计，尚未在业务应用上执行。实际服务地址、测试账号和令牌须在执行前准备。
Сценарии разработаны по OpenAPI, но ещё не выполнялись на приложении. Перед запуском нужны адрес сервиса, тестовые пользователи и токены.

| ID | 检查 / Проверка | 前提与输入 / Условия и ввод | 预期 / Ожидается |
| --- | --- | --- | --- |
| BC-01 | 活动列表 / Список встреч | GET /meetings?limit=20&offset=0 | 200，活动数组，可为空 / 200, массив, возможно пустой |
| BC-02 | 非法分页 / Неверный limit | GET /meetings?limit=0 | 400 |
| BC-03 | 正常报名 / Успешная запись | 已登录、活动存在、未报名，POST /meetings/{id}/registrations，无请求体 / Вход выполнен, встреча существует, записи нет; POST без тела | 201，一条报名 / 201, одна запись |
| BC-04 | 不存在的活动 / Нет встречи | 已登录，正整数 id 对应不存在的活动 / Вход выполнен, положительный id отсутствующей встречи | 404，不保存 / 404, без записи |
| BC-05 | 重复报名 / Повторная запись | 已登录且已报名同一活动，再次 POST / Вход выполнен, запись уже есть, повторный POST | 409，不重复保存或提醒 / 409, без дублей |
| BC-06 | 未认证 / Нет аутентификации | 报名 POST 不带令牌 / POST записи без токена | 401 |

本地文档检查使用 python tools/check_docs.py，运行结果见 verification.md。该检查不访问业务 API。
Документация проверяется командой python tools/check_docs.py; результат приведён в verification.md. Скрипт не обращается к бизнес-API.
