# 用户指南 / Руководство пользователя

维护角色 A。本文描述图书俱乐部设计中的使用流程；实际服务地址由课程部署提供。
Ответственный — A. Здесь описан проектный сценарий; фактический адрес сервиса задаётся учебным развёртыванием.

## 查看活动 / Просмотр встреч

前提：活动列表服务可访问。打开活动列表，查看主题、时间和地点，选择要参加的活动。
Условие: сервис списка доступен. Откройте список, проверьте тему, время и место и выберите встречу.

预期：显示活动；没有活动时显示空列表。接口 GET /meetings 正常返回 200。
Ожидается список встреч либо пустой список. Успешный GET /meetings возвращает 200.

## 报名活动 / Запись на встречу

前提：参与者已经登录，活动存在，尚未报名。进入活动详情，执行报名，查看确认结果。
Условие: участник вошёл, встреча существует и запись ещё не создана. Откройте встречу, выполните запись и проверьте подтверждение.

预期：创建一条报名，接口返回 201。系统在事务提交后安排提醒；提醒故障不代表报名失败。
Ожидается одна запись и ответ 201. Напоминание планируется после транзакции; сбой письма не означает отмену записи.

## 异常处理 / Ошибки

- 401：重新登录后再操作。 / 401: повторно войдите.
- 404：返回列表，重新选择存在的活动。 / 404: выберите существующую встречу.
- 409：已经报名，勿重复提交。 / 409: запись уже существует, повторять не нужно.
